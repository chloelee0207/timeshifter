# Time Shifter: KL → London

A one-page jet lag plan for the Kuala Lumpur → Singapore → London Gatwick trip
(SQ127 + SQ314, 23–24 Sep 2026). Open `index.html` in any browser.

- **Right now** card: what to do at this moment and what's coming up, updated live.
- Toggle between **KL time** and **London time**.
- Each day has a 24-hour strip (sleep / light / coffee / flight) and a list of steps.
- Today and the flights follow the Timeshifter app plan. The days after landing
  continue with the same approach for a 7-hour westward shift, including when a
  1 mg melatonin is (and isn't) worth taking.

## Publishing on GitHub Pages

One-time setup: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
After that, every push to `main` deploys the site.
